# 📐 คลังใบงานและข้อสอบปฏิสัมพันธ์: หลักการนับเบื้องต้นและความน่าจะเป็น ม.4
### Interactive & Print-Ready Mathematics Platform for Grade 10 (IPST Thailand)

แพลตฟอร์มสื่อการเรียนรู้และใบงานคณิตศาสตร์เชิงปฏิสัมพันธ์ (Interactive Web Application) ระดับชั้นมัธยมศึกษาปีที่ 4 เรื่อง **หลักการนับเบื้องต้นและการเรียงสับเปลี่ยน-จัดหมู่** รวมถึง **ความน่าจะเป็น** อ้างอิงตามหลักสูตรแกนกลาง สสวท. (ฉบับปรับปรุง 2560) และแนวข้อสอบเข้ามหาวิทยาลัย (A-Level คณิต 2 / O-NET)

---

## ✨ จุดเด่นของโปรเจกต์ (Key Features)

* **💻 ใช้งานได้ทันที (Single-Page Self-Contained)**: รวมโค้ด HTML, Inlined Tailwind CSS และระบบเรนเดอร์สมการคณิตศาสตร์ไว้ในไฟล์เดียว ไม่ต้องติดตั้ง dependencies หรือฐานข้อมูลใด ๆ สามารถดับเบิลคลิกเปิดใช้งานแบบ Offline ได้ทันที
* **⚡ เร็ว แรง ลื่นไหลทุกอุปกรณ์ (Cross-Device 60 FPS)**:
  * ปรับแต่งพิเศษสำหรับ **iPhone, iPad (Safari/WebKit)** และคอมพิวเตอร์ ไร้อาการสะดุด (Zero Lag)
  * ใช้ **Inlined Compiled Tailwind CSS (~27 KB)** ตัดภาระการคอมไพล์ runtime บนเบราว์เซอร์
  * ระบบ **Lazy Math Rendering** สั่งเรนเดอร์สมการ KaTeX เฉพาะบทเรียนที่เปิด ช่วยลด DOM nodes และหน่วยความจำลงกว่า 80%
  * ปรับ Touch Ergonomics ตัด Tap Delay 300ms และรองรับ Safe Area ขอบจอ iPhone/iPad (Notch & Dynamic Island)
* **📚 ครอบคลุม 10 หมวดการเรียนรู้ รวม 198 ข้อ**:
  * **บทที่ 1–7 (ใบงานเนื้อหาหลักสูตร สสวท.)**: หลักการบวก, หลักการคูณ, โจทย์ผสม, แฟกทอเรียล, การเรียงสับเปลี่ยนเชิงเส้น, การจัดหมู่, และความน่าจะเป็น (รวม 88 ข้อ)
  * **แนวข้อสอบประจำหน่วย (6 ฉบับเต็ม)**: แนวข้อสอบหลักการนับ 3 ฉบับ (30 ข้อ) และแนวข้อสอบความน่าจะเป็น 3 ฉบับ (30 ข้อ) รวม 120 คะแนน
  * **คลังข้อสอบรวมมาตรฐาน (5 ชุด 50 ข้อ)**: รวมแนวข้อสอบ สสวท. ประยุกต์, O-NET ย้อนหลัง, A-Level คณิต 2 และสปีดเทสต์ปราบเซียน
* **🖨️ พิมพ์ลงกระดาษ A4 ได้สวยงาม (Print-Ready)**:
  * จัดหน้ารองรับกระดาษ A4 อัตโนมัติ (`@media print`) พร้อมฟังก์ชันป้องกันการตัดแบ่งข้อสอบครึ่งแผ่น (`avoid-break`)
  * ปรับซ่อนปุ่มและแถบเมนูที่ไม่จำเป็นเมื่อสั่งพิมพ์ พร้อมระบบ **Print Safeguard** ตรวจสอบการเรนเดอร์สูตรครบ 100% ก่อนพิมพ์
* **✍️ พื้นที่เขียนวิธีทำแบบ 2 ระดับ (Tiered Student Writing Area)**:
  * **ระดับมาตรฐาน (Standard Tier - 96px)**: รองรับโจทย์คำนวณสูตรตรง 1–2 ขั้นตอน (เขียนได้ ~3 บรรทัด)
  * **ระดับลึก/หลายกรณี (Deep Tier - 144px)**: รองรับโจทย์เงื่อนไขซับซ้อน, โจทย์ผสม และข้อสอบเข้ามหาวิทยาลัย (เขียนได้ ~5–6 บรรทัด)
* **👁️ ระบบเปิด/ซ่อนเฉลย (Solution Toggle)**:
  * เลือกระหว่าง **"โหมดใบงานเปล่า"** ให้นักเรียนทำ หรือ **"โหมดใบเฉลยละเอียด"** สำหรับครูผู้สอนตรวจและอธิบายขั้นตอนวิธีทำ

## 🚀 วิธีการใช้งาน (Getting Started)

### 1. เปิดใช้งานแบบ Local (ในเครื่องตัวเอง)
* ดับเบิลคลิกเปิดไฟล์ `index.html` ผ่านเว็บเบราว์เซอร์ใดก็ได้ เช่น Google Chrome, Microsoft Edge, Safari หรือ Firefox

### 2. เผยแพร่ออนไลน์ฟรีผ่าน GitHub Pages
1. อัปโหลดไฟล์ทั้งหมดขึ้น GitHub Repository ของท่าน
2. ไปที่แท็บ **Settings** ของ Repository
3. ที่เมนูด้านซ้าย เลือกหัวข้อ **Pages**
4. ในส่วน **Build and deployment > Branch**:
   * เลือก Branch: `main`
   * เลือก Folder: `/ (root)`
5. กดปุ่ม **Save** จากนั้นรอประมาณ 1–2 นาที จะได้รับลิงก์ URL สำหรับเปิดใช้งานออนไลน์ได้ทันที (เช่น `https://<username>.github.io/<repo-name>/`)

### 3. การแก้ไขและคอมไพล์ CSS เพิ่มเติม (สำหรับผู้พัฒนา)
หากในอนาคตมีการเพิ่มคลาส Tailwind ใหม่ใน `index.html` สามารถรันคำสั่ง:
```bash
npm run build
```
ระบบจะคอมไพล์ CSS ใหม่และฉีดเข้าไปใน `index.html` โดยอัตโนมัติ
